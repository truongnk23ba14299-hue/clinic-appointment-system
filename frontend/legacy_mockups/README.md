# Thư mục Legacy Mockups (Bản mẫu HTML/CSS tĩnh ban đầu)

Thư mục này lưu trữ các file giao diện HTML/CSS/JS thuần ban đầu được dùng làm bản mẫu thiết kế (mockups).

### Lưu ý quan trọng:
- Toàn bộ ứng dụng chính thức hiện tại hoạt động dưới dạng **Single Page Application (SPA)** viết bằng **React 18 + Vite** nằm trong thư mục `src/`.
- Các file trong thư mục này chỉ dùng để đối chiếu giao diện khi cần, không ảnh hưởng đến build hoặc runtime của ứng dụng React.
